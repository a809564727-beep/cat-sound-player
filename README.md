# 喵百科 · 猫咪百科在线网站

收录 30 种热门猫咪的中文动态图鉴。纯静态站点（HTML / CSS / JS），无需构建，也无外部图片依赖：
所有猫咪均由 SVG + CSS 程序化绘制，支持 发呆 / 睡觉 / 玩耍 / 开心 四种动态状态。

## 功能
- 30 种猫咪卡片，实时动画；鼠标悬停会跳起来
- 点击猫咪，右侧展示详细介绍（桌面端侧栏，手机端底部抽屉）：简介、体重寿命、性格、六维评分、护理要点、趣闻
- 搜索、分类筛选、收藏（本地保存）、键盘 ← → 切换、`#品种id` 深链接
- 榜单推荐、新手养猫指南、响应式布局、支持“减少动态效果”系统设置

## 运行
直接打开 `index.html`，或 `python3 -m http.server` 后访问。部署到任意静态托管（GitHub Pages / Vercel / Netlify）即可。

猫咪数据在 `js/data.js`，绘制逻辑在 `js/cat.js`，新增品种只需添加一条数据。
